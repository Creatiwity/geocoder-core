## [0.2.0] - 2026-11-16

First release on crates.io.

### Features

- Luxembourg (BD-Adresses) and Belgium (BeST Address) registers, with the
  `lu` and `be` profiles
- geocoder-api, a BAN compatible API for several countries
- Helm chart, image and CI for geocoder-api
- Docker Compose deployment for a single host
- Signed prebuilt indexes: `publish` in CI, `update` downloads and checks
  them (`GEOCODER_INDEX_BASE_URL`), `signed` feature of the crate
- Index reading hardened: bounds checked offsets, FST checksums, bounded
  documents; a damaged index fails or comes back empty, never panics

### Fixes

- **chart**: API memory request from measurements

### Documentation

- READMEs for crates.io and the repository, release guide

### Maintenance

- Build the country indexes in CI and measure them
- **deps**: update dependencies, pin the toolchain
- Release to crates.io, package check, actions updated

## [0.1.0] - 2026-09-30

### Features

- Initial geocoder-core implementation (4ddc336)
- Synonyms and housenumber matching (562ac90)
- Query length validation (min 2, max 200 chars) (723f05f)
- Autocomplete distance scoring, score weights fixed (2a7d8c4)
- Common tokens as a secondary filter for overflow results (d0e236a)
- Results extended by reducing the token threshold down to 1 (1cb47e6)
- Results extrapolated through token pair co-occurrences (c06f68f)
- Autocomplete with edge ngram prefix sets (65a48ab)
- `SearchResult::label()` for human-readable display strings (68c7537)
- BANO / addok sjson.gz support in geocoder-build (230b0e4)
- HTTP source streamed directly into the index builder (b347e5d)
- `geocoder-search` binary (9f838c3)
- Faithful addok port with per-country profiles (9a83c32)

### Fixes

- BANO postcode/city as a string or an array, collected results
  deduplicated (0a642c1)
- `StringOrVec` for every BANO field that can be an array (dcdf64d)
- Full query scored against the full label with bigram Dice, as addok
  (fb567ff)
- Primary city only in labels, matched housenumber in the label score
  (8d5e5b3)

### Documentation

- Scoring documentation (1617a3f)
